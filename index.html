06 / BEYOND THE CLASSROOM
PYTHON × ASTRONOMY

What happens when Python meets the universe?

This summer, I also had the opportunity to take Python far beyond the projects we normally build in camp.

At Brown University, I used Python and machine learning as part of a research project exploring how numerical data can be used to identify distant quasars using Gaia astronomical data.

I worked with two different machine learning models (Logistic Regression and a Random Forest Ensemble) to see whether computers could distinguish quasars from Milky Way objects.

This is a demonstration that Python isn't just for games, calculators, or text display. The same language our students are learning can be used to investigate questions about the universe.
