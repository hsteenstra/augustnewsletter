06 / BEYOND THE CLASSROOM
PYTHON × ASTRONOMY

What happens when students teach?

This summer, I also had the opportunity to take Python far beyond the projects we normally build in camp.

At Brown University, I used Python and machine learning as part of a research project exploring how data can be used to identify distant quasars using Gaia astronomical data.

It was a reminder that Python isn't just for games, calculators, or little programs. The same language our students are learning can be used to investigate questions about the universe.
