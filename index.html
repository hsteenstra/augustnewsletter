We’re building something new for students and teachers: a free, browser-based Python sandbox designed to make learning, experimenting, and creating with code easier.

01 / WHAT IS A SANDBOX?

Think of it as a coding playground.

A coding sandbox is a place where you can write and run code without having to set up a complicated programming environment first.

Students can open the sandbox, start writing Python, press run, see what happens, change their code, and try again. It turns programming into something they can immediately experiment with.

01

No setup.

No downloads, complicated installations, or programming environment to configure. Open it in a browser and start coding.

02

Built to experiment.

Students can test ideas, make mistakes, change their programs, and see the results immediately. That experimentation is a huge part of learning to code.

03

Made for classrooms.

The sandbox is designed to be useful beyond summer camps — as a resource students and teachers can return to while learning computer science.

BUILT FOR WHAT COMES NEXT

From the workbook to the browser.

We’re thinking beyond a single coding tool. As Code For ME develops future workbooks and classroom resources, the sandbox can become the place where students actually write and run the code they’re learning about.

A lesson could introduce a concept, a workbook could guide students through it, and the sandbox could give them a place to try it themselves — all working together.

06 / BEYOND THE CLASSROOM
PYTHON × ASTRONOMY

What happens when Python meets the universe?

This summer, I also had the opportunity to take Python far beyond the projects we normally build in camp.

At Brown University, I used Python and machine learning as part of a research project exploring how numerical data can be used to identify distant quasars using Gaia astronomical data.

I worked with two different machine learning models (Logistic Regression and a Random Forest Ensemble) to see whether computers could distinguish quasars from Milky Way objects.

This is a demonstration that Python isn't just for games, calculators, or text display. The same language our students are learning can be used to investigate questions about the universe.
